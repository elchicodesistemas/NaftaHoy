Visión General del Proyecto

Portal web de referencia para consultar precios de combustibles actualizados en Argentina

⛽

¿Qué es NaftaHoy?

Un portal web que muestra los precios actualizados de nafta, diésel y GNC de todas las petroleras de Argentina (YPF, Shell, Axion, Puma, PAE, etc.), siguiendo el modelo exitoso de DolarHoy.com pero aplicado al mercado de combustibles.

Dominio: NaftaHoy.com Server: Ubuntu
🎯

Objetivo Principal

Convertirse en la fuente #1 de consulta de precios de combustibles en Argentina. Consumir APIs de petroleras y fuentes oficiales, almacenar históricos, y monetizar mediante publicidad y servicios premium (como hace DolarHoy con las cotizaciones).

Monetizable Escalable
👥

Público Objetivo

Conductores que buscan el mejor precio antes de cargar. Flotas de transporte y logística. Medios de comunicación que necesitan datos de referencia. Analistas del sector energético y economistas.

B2C B2B
📊

Propuesta de Valor

Información centralizada, actualizada y confiable. Comparativas entre petroleras por zona. Históricos de precios y tendencias. Alertas de cambio de precios. Todo en una interfaz rápida, mobile-first y SEO optimizada.

Fuentes de Datos Identificadas

APIs y fuentes verificadas para obtener precios de combustibles

✅

Shell Developer Portal — PriceList API

API oficial de Shell que permite obtener precios de estaciones Shell y sitios asociados. Incluye precios en surtidor y descuentos aplicables. Requiere registro como developer partner.

developer.shell.com/api-catalog

API REST Oficial Requiere registro
✅

Secretaría de Energía — Datos Abiertos

Por Resolución 314/2016, las estaciones de servicio DEBEN declarar precios dentro de 8hs de cualquier cambio. Datos disponibles en datos.energia.gob.ar y datos.gob.ar. Incluye precios históricos y datos por estación.

datos.energia.gob.ar • datos.gob.ar

Datos Abiertos Oficial Gov Gratuito
🔧

Precios en Surtidor — Mapa Web

Sistema web del Ministerio de Energía con mapa interactivo. No tiene API pública pero existe un scraper open source en GitHub (andytow/surtidores). Datos casi en tiempo real.

preciosensurtidor.energia.gob.ar

Scraping Tiempo real Open Source
🔧

YPF / Axion / Puma — Webs Oficiales

Las petroleras publican precios en sus webs oficiales. No ofrecen APIs públicas (excepto Shell), pero se pueden scrapear de forma controlada y respetuosa con cron jobs programados.

Scraping Sin API pública
📊

Datos.gob.ar — Dataset Históricos

Dataset oficial con precios históricos de combustibles. Formato CSV descargable. Ideal para construir gráficos de tendencia y análisis comparativo entre períodos.

datos.gob.ar/dataset/energia-precios-surtidor

CSV Gratuito Histórico

¿Por qué este Stack?

SEO es clave

DolarHoy.com recibe 62% de tráfico directo y 31% de búsqueda orgánica. Next.js con SSR genera HTML en el server, ideal para que Google indexe los precios. Esto es el factor #1 de éxito para un portal de este tipo.

Un solo lenguaje

TypeScript en frontend y backend = mismo equipo puede trabajar todo. Reduce complejidad, facilita contrataciones futuras, y tiene el ecosistema más grande de paquetes (npm).

Velocidad de carga

Redis cachea los precios más consultados. Nginx sirve assets estáticos. Next.js genera páginas estáticas donde puede (ISR). El usuario ve precios en <1 segundo.

Roadmap de Desarrollo

Plan de ejecución por fases

FASE 0 — Semana 1-2 · Investigación & Setup

Preparación del Terreno

Configurar servidor Ubuntu (Docker, Nginx, SSL con Let's Encrypt). Registrarse en Shell Developer Portal y obtener API key. Analizar la estructura de datos de la Secretaría de Energía. Probar el scraper open-source de surtidores. Definir esquema de base de datos. Configurar repositorio Git y CI/CD básico.

FASE 1 — Semana 3-5 · MVP Backend

Motor de Datos

Desarrollar workers de ingesta (cron jobs) para cada fuente de datos. Crear el normalizador de datos (diferentes fuentes → formato unificado). Montar PostgreSQL + Redis. Construir la API REST interna. Implementar logs y monitoreo básico. Primer scraping funcional de al menos 2 fuentes.

FASE 2 — Semana 6-8 · MVP Frontend

La Vidriera

Diseñar la home page al estilo DolarHoy (precios grandes, claros, con variación). Crear páginas por petrolera, por tipo de combustible, por zona. Implementar gráficos de evolución histórica. SEO on-page: meta tags, schema.org, sitemap. Mobile-first responsive design. Conectar con la API interna.

FASE 3 — Semana 9-10 · Lanzamiento Beta

Salida al Mundo

Deploy en producción. Configurar dominio NaftaHoy.com. Registrar en Google Search Console y enviar sitemap. Instalar Google Analytics. Testing de carga y rendimiento. Feedback de usuarios beta.

FASE 4 — Semana 11-14 · Crecimiento

Tracción & Monetización

Integrar Google AdSense / redes de publicidad. Desarrollar sistema de alertas (email, push). Crear API pública con plan freemium. Agregar comparador de estaciones por cercanía. Contenido editorial (análisis de mercado, notas). Redes sociales automatizadas.

FASE 5 — Mes 4+ · Escala

Expansión

App móvil nativa o PWA avanzada. Geolocalización (estación más cercana + más barata). Partnerships con estaciones de servicio. Dashboard premium para flotas/empresas. Expansión a otros países de la región (GNaftaHoy, etc.).

Estrategia de Monetización

Modelo de ingresos diversificado, inspirado en DolarHoy.com

📢

Publicidad Display

Ingreso base
Google AdSense + redes programáticas. Banners en home, páginas de detalle y comparativas. CPM/CPC según tráfico. Es el modelo principal de DolarHoy.com.
🔌

API as a Service

Freemium
API pública con tier gratuito (100 req/día) y planes pagos para desarrolladores, apps, medios y empresas que necesiten datos de precios. Modelo SaaS recurrente.
⭐

Estaciones Destacadas

Sponsorship
Las estaciones de servicio pagan por aparecer destacadas en el buscador o en los resultados de "más barata cerca tuyo". Similar a Google Maps promoted pins.
📊

Datos & Reportes

B2B Premium
Reportes analíticos del mercado de combustibles para consultoras, petroleras, fondos de inversión. Datos históricos procesados, tendencias y predicciones.
📧

Alertas Premium

Suscripción
Notificaciones instantáneas de cambio de precios por zona, por petrolera. Versión gratuita limitada + versión premium con filtros avanzados y múltiples canales.
🏢

Widget Embebible

Freemium
Widget HTML que medios y blogs pueden embeber (como el de DolarHoy). Versión gratis con marca NaftaHoy, versión paga white-label sin marca.

Análisis de Competencia

Competidores directos e indirectos identificados

⛽ Naftas.com.ar

Portal con precios de nafta actualizados por localidad. Interfaz funcional pero básica. No ofrece API ni datos históricos avanzados.

naftas.com.ar
Competidor directo

🏪 Surtidores.com.ar

Portal líder de estaciones de servicio desde el año 2000. Enfocado en noticias del sector + precios. Audiencia establecida pero diseño antiguo.

surtidores.com.ar
Competidor directo

📱 Donde cargAR

App móvil privada lanzada en 2023. Enfocada en geolocalización y comparación. Solo mobile, no tiene presencia web fuerte para SEO.

Solo mobile

🏛️ Precios en Surtidor (Gov)

Portal oficial del gobierno. Datos confiables pero UX pobre, sin gráficos, sin comparativas, sin históricos accesibles. Es fuente de datos, no competidor real.

preciosensurtidor.energia.gob.ar
Fuente de datos

💰 DolarHoy.com (modelo)

No es competidor sino referencia. ~3M visitas/mes. 62% tráfico directo. Monetiza con publicidad display. Demuestra que el modelo funciona en Argentina para datos financieros/precios.

dolarhoy.com
Modelo a seguir

Ventaja Competitiva de NaftaHoy

Ninguno de los competidores actuales combina: (1) diseño moderno mobile-first, (2) datos de TODAS las petroleras en un solo lugar, (3) API pública para desarrolladores, (4) históricos con gráficos de tendencia, y (5) alertas de cambio de precios. Hay una oportunidad clara de posicionarse como la referencia del sector.
